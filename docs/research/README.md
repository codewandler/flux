# docs/research

**Living** competitor deep-dives, each dated and refreshed in place. A page here exists because
someone read a competitor's shipped surface end to end and mined it for features worth having in
flux — so the next person doesn't repeat the read, and doesn't re-litigate what was already
rejected.

Not to be confused with [`../archive/research/`](../archive/research/): that is the **inception
snapshot** (~2026-06-25) — the nine-category landscape, the master matrices, and the per-cluster
profiles. It is preserved for provenance and is *not* maintained. When a page here supersedes part
of it, the archived text gains a one-line pointer and is otherwise left alone.

## What a page here must contain

1. **An observation header** — the source, the date, and what kind of source it is (a vendor manual
   states intent as well as shipped behavior; treat it accordingly).
2. **The delta** against whatever flux's docs currently say about that competitor.
3. **A verdict per feature** — `mine` / `have` / `reject` — where `have` and `reject` carry the
   reason, and `mine` carries `file:line` evidence that the gap is real in flux today.
4. **Filed stories** for whatever survived, linked from the page.

A page is a mining record, not a scorecard. Positioning claims belong in
[`../vision.md`](../vision.md) and the archived landscape's Part 2.
