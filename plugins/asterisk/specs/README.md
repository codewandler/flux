# Vendored Asterisk ARI contract

`ari-22.10.1/` is generated by `../scripts/vendor-ari-specs.sh` from the official Asterisk
repository at tag `22.10.1`. The annotated tag object
`4f85d05889cf9fb9c9e2ae44cc3f4a825a74545a` peels to source commit
`f0e408a7b0d829c85bf15fa4b487870a50cb3000`; provenance pins both identities. The directory
contains the top-level ARI `resources.json`, all eleven resource documents that file declares,
their SHA-256 provenance, and the upstream license.

`ari-22.10.1.sha256` is the authored trust anchor. Both network fetches and local-source replays are
checked against it before generated provenance or repository files are written.

The specification files retain their upstream copyright notices. Asterisk distributes these files
under GPL-2.0-only; the exact upstream `COPYING` is included beside them. This attribution applies
to the vendored Asterisk material, not to Flux's independently authored plugin implementation.
The Swagger files are development-only generator inputs: they are not embedded in or packaged with
the plugin binary. D-243 generates separately authored, committed Rust contracts from them.

Regenerate those contracts after refreshing the vendored documents, then verify the committed
output is current:

```bash
plugins/asterisk/scripts/generate-ari-contracts.py
plugins/asterisk/scripts/generate-ari-contracts.py --check
```

Do not edit the generated directory. Refresh from the pinned public source:

```bash
plugins/asterisk/scripts/vendor-ari-specs.sh
```

Or reproduce the same bytes from an exact Asterisk source checkout:

```bash
plugins/asterisk/scripts/vendor-ari-specs.sh --source-dir /path/to/asterisk
```
